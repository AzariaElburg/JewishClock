1. What the clock shows

Short messages in the window, one after the other, over and over:

  • The Hebrew and the Gregorian date.
  • Shabbat and Yom Tov: candle lighting, Havdalah, the parasha, Shabbat Mevarchim, the special Shabbatot.
  • Holidays, Rosh Chodesh, fasts (start and end), the Omer.
  • Daf Yomi and Mishna Yomit.
  • Rain and dew in prayer (below).
  • Your events - birthdays, anniversaries, yahrzeits - with the age or the number of years.
  • When each one starts and stops showing: Calendar Content.
The day changesThe Hebrew date - and Chanukah candles with it - changes at צאת הכוכבים, as in printed calendars. The Gregorian date changes at midnight.
Events on a Hebrew dateShow from the evening before (when the Hebrew date begins), or from midnight - your choice in Calendar Content.
Event with both datesShows on each of them. A small blue Star of David after the age = it is the Hebrew date's turn; no star = the Gregorian date's. The age is counted in that calendar.

Rain and dew in prayer

Two separate reminders. After the day of a switch the clock shows only the words themselves.

משיב הרוח / מוריד הטלFrom Musaf of 22 Tishrei and of 15 Nisan. The day itself says "ממוסף", the days before it "ממחר".
ותן טל ומטר / ותן ברכהFrom the first weekday Maariv: 7 Cheshvan in Israel, 4 or 5 December abroad; after Pesach from Maariv when Yom Tov ends ("מהערב").
Abroad, nusach Ashkenaz, Pesach"בלי משיב הרוח ממוסף": from Musaf one stops saying משיב הרוח.

Nusach and the days shown around a switch: Calendar Content. Israel or abroad follows the clock's place (Wi-Fi, place and name).

Red notices about the clock itself

Among the messages the clock sometimes shows a notice in red - not every round, only now and then while the reason lasts. They are always in English. What to do about each: Troubleshooting.

No internet!The clock has not been on any Wi-Fi for a while. It goes on with the dates it has saved. With it: the name and password of the clock's own Wi-Fi.
No NTP for … daysThe internet works, but no time server has answered for a few days; the number goes on counting. The clock keeps time by itself meanwhile, slightly off.
NTP server refused - see SettingsA time server told the clock not to ask it again. Shown until that server is taken off the list (Advanced).
Update to … failedA new version did not start properly and the clock went back to the old one by itself. On the screen for a few days at most, or until OK, seen (Updates).
Error - see SettingsThe clock found something wrong by itself. Settings says what, at the top. Today: a name or text in the clock's own files that is longer than this version takes (usually from an older version; on the screen for a few days), or the update feed (the GitHub page where new versions are published - Updates) has been gone for a few days.
Clock's Wi-Fi: … - password …Not a problem: the clock's own Wi-Fi, in its first minutes after being plugged in and whenever it has no Wi-Fi.

OK, seen (under each problem in Settings): the clock stops showing that problem on its screen. Settings keeps listing it until it is put right. The Error - see Settings line goes when every problem is seen or put right. A new problem shows again.

2. Opening the clock's page

Everything is set from a phone or computer, in its browser - nothing to install.

Through the clock's own Wi-Fi (always works)

  1. In the Wi-Fi list choose the clock's own network - it has the clock's name, e.g. JewishClock. Password: on the printed start guide, in Settings → Wi-Fi, and on the clock's screen when it has no Wi-Fi.
  2. In the browser open the address on the clock's screen.
  3. When done, switch back to your usual Wi-Fi.
  • The page stops answering: choose the clock's Wi-Fi again - phones and computers sometimes leave a Wi-Fi without internet by themselves.
  • After the clock restarts (an update, an import) its Wi-Fi is gone for a minute; the page says when to choose it again.

Through the home network

  • jewishclock.local (the clock's name, no spaces), or the clock's address on that network.
  • Some routers don't let devices reach each other - then use the clock's own Wi-Fi.

First start, or after a factory reset

  1. The screen scrolls the setup Wi-Fi's name and password. Join it, open the address on the clock's screen.
  2. Pick the home Wi-Fi from the list, type its password, Connect.
  3. Or put back a backup: Restore from backup (Backup).

Finding a setting

In Settings, type a word in Search settings...

Adding or changing an event

  1. Click ＋ (new), or click an existing event.
  2. Name, and the type: Birthday, Wedding, Yahrzeit, Other.
  3. The date: Gregorian, Hebrew, or both. It starts at today (or at the day you clicked) - change what differs; the other calendar follows.
  4. Remind ... days before: also show the event that many days ahead ("in a few days").
  5. An icon or a picture (next section) - optional.
  6. Save.

Adar IIA leap year's second Adar.

Hebrew day and yearIn Hebrew letters, like כ״ג and תשפ״ז. Digits work too (23, 5787 or 787) and turn into letters.

Deleted events (Settings)Restore one, Restore selected, Restore all; Empty recycle bin deletes them for good.
  • Many events at once: edit them in Excel - Backup, import and restore.
  • An event that is refused says why on the page (a name too long, a date that does not exist, no room left); nothing is half saved.

7. Wi-Fi, place and name

  1. Settings → Wi-Fi.
  2. Change what you need, then Save Wi-Fi.
Clock nameLetters and digits only. Also the name of its own Wi-Fi and of name.local. A new name restarts the clock; its own Wi-Fi comes back under the new name.
Clock's own Wi-FiIts name and password. Change sets a new password (plain English letters, digits and signs; the page says how long it may be); the clock restarts, and phones and computers must join again with the new one. Write it down.
NetworksSeveral (home, family, a spare). The clock joins the one it was on last, otherwise the strongest it hears, and moves to a clearly stronger one when the signal stays weak. The green dot = the one it is on.
⋯ → ConnectMove to that network now.
⋯ → Change networkPick from the networks the clock hears, or Other… to type a name (Show shows the typed password).
⋯ → Change placeThe place (city) of that network.
⋯ → RemoveForget that network.
24-hour clockTimes as 18:30 or 6:30.
Reset Wi-FiForgets all networks; the clock opens its setup Wi-Fi.
  • A network's name and password: plain English letters, digits, spaces and signs only (no accented or Hebrew letters) - what every router takes. Anything else is refused, saying so.
  • Place: each network has its own place - for candle lighting, Havdalah, fasts, the time zone, Israel or abroad. When the clock joins a network, that network's place becomes active.
  • A new network's place is looked up from the internet and marked detected. Check it with Change place; a city can be searched by name, in English or Hebrew.

8. Backup, import and restore

The backup is one Excel file.

  1. Settings → Export & import.
  2. Choose Events, Settings or Both, then Export.
  3. Keep the file.
EventsAll events, with their pictures and the icons you replaced.
SettingsAll settings, Wi-Fi included.
BothEvents (with their pictures and replaced icons) and settings in one file - the full backup.
ImportA file exported before (it may be edited in Excel). The page shows what is in it and asks what to take. Events: replaces the event list - Undo is offered. Settings: replaces all settings and restarts the clock. A file that is not right is refused with the reason; nothing is changed.
Restore from backupFor a new or reset clock: on its setup page (First start) pick the file - events, pictures, settings and Wi-Fi come back.
Factory reset...(Advanced) Erases everything; offers a backup first.
  • The file names the clock software version that made it. A clock reads files of its own main version and of the one before; a newer file, or a much older one, is refused with the reason.

9. Updates

From a file (sent by email)

  1. Save the .jcupdate file.
  2. Settings → Clock software → Update the clock.
  3. Choose the file, Update.
  4. The clock restarts once. Choose the clock's Wi-Fi again when the page asks, and wait for Done.

From the internet

New versions are published on the update feed, a page on GitHub: github.com/AzariaElburg/JewishClock-Updates/releases.

By itselfThe clock asks the update feed once a day whether there is a newer version, and installs it at night - Install new versions at night by themselves (Clock software) on.
Check nowAsks at once.
Install <version>Appears when a newer version is there; installs it right away.
The line under Updates from the internetWhat the clock last heard; after a failed install it says why, until that version is installed.

What to know

  • A new version starts on trial: if it does not get on the Wi-Fi within a few minutes, or stops working, the clock goes back to the version it had, by itself. Settings and events are never touched.
  • Then the clock shows Update to … failed in red (Red notices) and Clock software shows it too, until OK, seen there - which ends both. Tell whoever sent the update.
  • Only update files signed by the clock's maker are installed. The clock checks them with its Update key. If a new key is ever sent: Paste a key - it replaces the old one. No key = no update is accepted.
  • An older version than the clock's is refused: it can't read the newer one's settings and events. The update page then offers Install the older version and erase everything - settings, events and pictures go (Wi-Fi stays). Export them to Excel first, and import them afterwards.
  • The manual and the pages come with each update, so they always match the version. What each version changed: Clock software → What's new.
  • If the clock's page does not work: /update-safe on the clock's address (built into the clock) installs an update too.

10. Advanced

Settings → Advanced, at the bottom - not needed in daily use.

Window calibrationOffset X, Offset Y, Width, Height, Calibrate: where the visible window is on the screen - only after a change to the box. Tear lines moves two thin lines that can appear in scrolling text above and below the letters.
DemoEverything the clock can show, once.
Debug timeTest the clock at another date: Shift by, Set to (Gregorian) or Set to (Hebrew), Apply. Always finish with Back to real time.
Holiday & times data (from Hebcal)Refresh now downloads it again, Clear cache drops the stored copy. Your events are not affected.
Log levelHow much the log records, and for how long: until the clock restarts, an hour, a day, a week, or always; then back to Info by itself.

Time servers

  1. NTP server 1, 2, ...: where the clock gets its time - it asks the first that answers, then the next.
  2. Drag ⠿ to change the order. Type a name to change a server.
A name you typeChecked first, saved only if that server answers. At least one must stay.
Not recommended (under a box)The server failed while the internet worked: no answer, an answer the clock can't use, or "ask me less often". It is asked last, once a day; after a few good answers on separate days the note goes by itself.
Refused by server (under a box)The server told the clock never to ask again; the clock does not. The clock shows NTP server refused - see Settings. Remove the server and add it again, or use another one.
Internet downNo server is blamed: the clock waits for the internet, then asks for the time at once.

11. Troubleshooting

First: unplug the clock and plug it in again. Safe at any time; nothing is lost.

No internet!Router off, out of reach, or its Wi-Fi password changed. The clock's own Wi-Fi stays up: open the page through it (Opening the clock's page) and, if the password changed, type the new one in Settings → Wi-Fi. The clock tries the home Wi-Fi again by itself.
Wi-Fi password forgottenUnplug the clock and plug it in again: in its first minutes it shows the name and password of its own Wi-Fi (Clock's Wi-Fi: … - password …).
No NTP for … daysCheck the time servers: Settings → Advanced, NTP server 1... A Not recommended note says which one fails. Everything else goes on meanwhile.
NTP server refused - see SettingsSettings → Advanced: the server marked Refused by server - remove it and add it again, or use another one. There is no OK, seen for this: it goes when the server is off the list.
Error - see SettingsOpen Settings: the problem is listed at the top - Too long for this version - please change: (the text, and the box to change it in; then save) or Something is wrong: (the update feed is gone - tell whoever maintains the clock). OK, seen only takes it off the clock's screen; Settings lists it until it is put right.
Update to … failedThe clock is still on its old version, nothing lost. Tell whoever sent the update; OK, seen in Settings → Clock software takes the notice away.
"Not saved: the clock's storage is full"The clock's storage has no room left. Free some: Settings → Pictures and icons - remove pictures and put replaced icons back to Original; Storage shows what is left.
Wrong times or holidaysCheck the place: Settings → Wi-Fi → ⋯ → Change place.
Empty or old calendarThe clock may have no internet; it keeps showing what it downloaded last.
The page does not openUse the clock's own Wi-Fi (Opening the clock's page); if the page is broken, /update-safe (Updates).
Get logSettings → Clock software → Problem report: a text file with the clock's log and settings (no passwords) - email it.
RecordWhen asked for it: Clock software → Web answers saves the clock's answers to its page in a file, in about half a minute - email it too. It contains the settings and events.

What each red notice means: Red notices about the clock itself.
