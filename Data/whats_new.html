JewishClock - What's new

Your events, pictures and settings stay as they are with every update.

Version 2.2.1

New

  • From this version on, each version has a What's new page like this one. Open it from Settings → Clock software → What's new.

Changed

  • A clock that is set up from new now makes its own Wi-Fi password and shows it on its screen. Clocks that are already set up keep their existing password.

Fixed

  • A rare problem when the clock checks its time is fixed.

Version 2.2.0

New

  • The clock now looks for a new version on the internet once a day and installs it by itself at night.
  • If you would rather decide yourself, turn off Install new versions at night by themselves in Settings → Clock software. A new version then waits there until you press Install.
  • If an update does not work, the clock still goes back to its old version by itself. It now also tells you: a red line on the clock and a note in Clock software say which update failed, until you press OK, seen.
  • When the clock loses its internet connection, it now shows the name and password of its own Wi-Fi every few rounds, so you can still open its page. It also shows them for the first few minutes after it is switched on.
  • The password of the clock's own Wi-Fi can be changed in Settings → Wi-Fi → Change.
  • When the clock finds a problem by itself, its screen shows Error - see Settings, and the top of Settings says what is wrong.
  • The clock installs only updates that are signed by its maker.

Changed

  • When you change the order of the messages in Calendar Content, the clock follows the new order from its next message.
  • Installing an update now restarts the clock once instead of twice.
  • A name or text that is too long is now refused with a message saying why. Before, it was cut short without a word.
  • Changing the clock's name now restarts the clock, so the new name is used everywhere at once.
  • The Mishnah Yomit message has a new picture.

Fixed

  • The 24-hour clock setting now changes the times on the clock (candle lighting, Havdalah, fasts). Before, it was saved but not used.
  • An icon you make from an emoji or a few letters now shows on the clock. Before, it stayed blank.
  • When the clock's storage was full, saving the events could lose all of them at the next restart. The clock now checks for room first, and tells you if there is none.
  • After several weeks without a restart, the clock could stop setting its time. It now keeps it right however long it runs.
  • After the clock got back onto the home Wi-Fi, its own Wi-Fi could keep the name it uses during setup.
